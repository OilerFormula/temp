# EVRIMA 스탯 비교

The Isle Evrima 공룡 성장 비교 사이트. 빌드 도구나 백엔드 없이 GitHub Pages에서 동작합니다.

사이트: https://oilerformula.github.io/temp/ (비밀번호 잠금 화면 적용)

## 기능

- 여러 공룡을 체중 / 달리기 / 공격력 그래프에 동시에 비교
- 선택 공룡끼리 색 중복 없이 대비가 큰 색을 우선 배정. 기존 선택의 색은 유지하고 그래프·목록·수치 표에 동일하게 적용·저장
- 그래프마다 공룡 표시 켜기·끄기
- 질주, 차징/Ambush, 갈리미무스 영양·Mobilize·무리 보정, 스태미나 항목 선택
- 물기와 추가 공격 종류별 표시 켜기·끄기
- 초기 선택: Carnotaurus / Ceratosaurus. 왼쪽 목록은 영어 이름 위, 한국어 이름 아래.
- 그래프 아래 축의 0 / 25 / 50 / 75 / 87.5 / 100% 숫자를 클릭하여 선택. 다른 값은 그래프 좌클릭 또는 개별 성장치 입력
- 설정의 전체 성장치 슬라이더와 단계 버튼은 모든 그래프의 선택 성장치를 함께 변경. 커서 이동이나 개별 그래프 선택은 슬라이더 값을 바꾸지 않음
- 넓은 설정 박스에서는 성장 경로·버전과 성장치 슬라이더를 좌우로 배치하고, 작은 화면에서는 너비를 채워 세로로 배치
- 커서 이동은 퍼센트만 표시하고, 좌클릭으로 해당 그래프의 선택값만 변경
- 모든 박스 접기, 박스 상단 드래그 바로 순서 변경·애니메이션·저장. 설정 박스는 항상 맨 위 고정
- 그래프 확대보기, 축소 또는 ESC로 닫기. 확대 화면에서도 필터·입력·버튼 동작
- Prime/Frail 경로, 체중 로그 눈금, 미출시 공룡 포함
- 원본 사이트 최신 버전 및 특수능력 보정값 연결 / 수동 업데이트
- 마지막 성공 데이터 브라우저 저장, 연결 실패 시 저장 데이터 유지
- 현재 표시 설정대로 성장률 0~100% / 1% 간격 CSV 내보내기
- 21종의 성장시간 비교, 서버 배율, 식성 보너스 +0~300% (기본 1배에 더하는 방식)
- 0~75% 사이 겹치지 않는 구간별 식성 설정, 시작·목표 성장률과 누적 소요시간
- 75~100%는 식성 보너스를 항상 0%로 고정하고 서버 성장 배율만 적용
- 성장시간 그래프 개별 공룡 ON/OFF, 전체 선택, 시간 CSV 내보내기
- 22종의 기본 스태미나 회복값과 휴식 시간별 회복 배율 표, 선택 공룡/전체 전환, CSV 내보내기
- 별도 참고 시간표의 질주 지속 시간·휴식/서기/걷기/속보 회복 시간, 회복 시간의 15% 버프 선택
- 스태미나 박스도 접기·드래그 이동·확대·축소 지원

## GitHub Pages

대상 저장소: https://github.com/OilerFormula/temp

1. 이 폴더의 파일을 저장소 `main`에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다.
3. push 시 `.github/workflows/pages.yml`이 수치 검증과 배포를 수행합니다. 기존 파일 업로드 후에는 Actions에서 **Deploy Evrima Compare → Run workflow**로 실행할 수 있습니다.
4. 일반적인 기본 주소는 `https://oilerformula.github.io/temp/`입니다. 실제 배포 성공 주소는 Actions의 deployment output에서 확인하세요.

모든 내부 경로는 상대 경로이므로 `/temp/` 같은 저장소 하위 경로에서도 동작합니다. 사용자별 공룡 선택과 데이터 캐시는 해당 브라우저에 저장됩니다.

## 로컬 실행

Windows에서는 `start-preview.cmd`를 두 번 클릭하면 브라우저와 로컬 미리보기가 열립니다. Python 3이 필요합니다. 실행 창을 닫으면 서버가 종료됩니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:4173/ 을 엽니다. ES modules와 JSON 요청을 사용하므로 `index.html`을 파일로 직접 여는 방식 대신 HTTP 서버를 사용하세요.

```powershell
node --test
node scripts/build.mjs
```

추가 패키지 설치 없이 실행됩니다. Node 22 이상 또는 24, Python 3 권장.

## 데이터 갱신

사이트의 **스탯 업데이트** 버튼은 원본의 `/data/index.json`을 읽고 최신 버전의 `species.json`, `foods.json`을 받습니다. 원본 HTML에서 현재 JavaScript 경로를 찾아 특수능력 상수를 안전하게 읽습니다. 내려받은 JavaScript를 실행하지 않습니다.

첫 화면은 포함된 JSON 또는 마지막 성공 캐시로 즉시 표시합니다. 이후 원본을 확인합니다. 업데이트 실패 시 현재 그래프 데이터는 유지하고 실패 상태를 표시합니다. 원본 구조가 변경되면 기존 값으로 조용히 덮어쓰지 않습니다. 특수능력만 갱신에 실패한 경우 같은 버전의 캐시만 사용하며 상태를 알립니다. 과거 버전에는 최신 버전의 능력 보정값을 적용하지 않습니다.

배포에 포함할 기본 데이터 스냅샷도 갱신하려면:

```powershell
node scripts/update-data.mjs
node --test
```

`data/` 변경을 커밋하고 push하면 Pages가 다시 배포됩니다. 방문자의 데이터 업데이트는 저장소를 수정하지 않습니다.

## 성장시간 자료와 갱신

성장시간은 Evrima Viewer가 제공하지 않는 별도 커뮤니티 자료입니다. `data/growth-times.json`에 각 종의 출처 URL, 확인일, 0~25 / 25~50 / 50~75 / 75~100% 기본 시간을 저장합니다. 2026-10-12에 [Evrima Quick Guide](https://www.evrimaquickguide.com/)의 21종 프로필을 직접 읽고 네 단계의 합계와 원본 총시간을 대조했습니다. Austroraptor의 알려진 복사/임시 수치는 제외했고, 미출시·자료 미확인 종은 자료 없음으로 표시합니다. Deinosuchus와 Beipiaosaurus는 원본의 마지막 단계 이름이 Adult인 항목을 75~100%로 해석합니다.

각 단계 안의 시간은 성장률에 비례하는 추정값입니다. 식성 구간과 25/50/75% 경계에서 정확히 나눠 계산합니다. 식성 보너스는 `1 + 값/100`을 서버 배율에 곱하는 방식 하나로 통일했습니다. +0%=기본 1배, +180%=2.8배, +300%=4배입니다. 75% 이후에는 식성 배율을 1로 고정합니다. Prime/Frail의 시간은 별도 자료가 없어 동일하게 계산합니다. 기존 브라우저에 저장된 해석 선택은 제거하고 저장된 숫자를 추가 보너스로 적용합니다.

기본 시간 갱신은 GitHub 저장소 **Actions → Update growth baselines → Run workflow**에서 실행합니다. 원본 21종을 다시 읽고 검증·커밋·사이트 배포까지 수행합니다. 원본 구조 변경이나 일부 수신 실패 시 기존 스냅샷을 교체하지 않습니다. 방문자의 식성 설정은 해당 브라우저에 저장되며 이 기본 시간을 수정하지 않습니다.

로컬에서 갱신하려면:

```powershell
python scripts/update-growth-data.py
node --test
```

## 스태미나 자료와 갱신

`data/stamina-reference.json`은 [MyIsleMap 기본 회복값](https://myislemap.com/Dinosaur-Stamina-Regeneration-by-State.html)과 [휴식 시간별 배율](https://myislemap.com/Dinosaur-Rest-Multiplier-by-Time.html)의 공개 JSON을 읽고 검증한 스냅샷입니다. 22종의 상태별 설정값과 0~200초의 1초 간격 배율이 있습니다. 식성·상태 보정이 제외된 기본 설정값이며 물리적 단위가 명시되지 않아 %/s나 포인트/s로 바꾸지 않습니다. 총 스태미나·성장 단계·게임 버전 정보도 미제공이므로 성장 그래프나 완전 회복시간을 계산하지 않습니다. 전체 성장치, Prime/Frail, 성장시간 식성 설정은 이 표에 영향을 주지 않습니다.

[Evrima Quick Guide](https://www.evrimaquickguide.com/gameplay/health-statuses/stamina)의 21종 시간표는 별도 참고 자료로 분리합니다. 이 출처는 오래된 정보 갱신 안내를 표시하며 버전·성장 단계가 명시되지 않았습니다. 지속 시간은 No Buff 값만 표시하고, 15% 버프 선택은 회복 시간에만 적용합니다. 서기20→100%, 걷기·웅크리기40→100%, 속보60→100%와 휴식0→100%를 구분합니다. Deinosuchus 육상/수중, Maiasaura 사족/이족, Pteranodon 매달림 조건을 보존합니다. 시간 자료가 없는 Austroraptor는 자료 없음으로 표시합니다.

원본은 브라우저 교차 출처 접근을 허용하지 않아 GitHub 저장소 **Actions → Update stamina reference → Run workflow**로 갱신합니다. 원본을 다시 읽고 구조·수치·공룡 목록·시간표를 검증한 후 스냅샷을 커밋하고 사이트를 배포합니다. 수신 실패나 구조 변경 시 이전 자료를 교체하지 않습니다. 사이트의 **스탯 업데이트**는 배포된 회복표를 다시 읽으며, 실패 시 현재 표를 유지합니다. 표에 실제 자료 확인일을 표시하고 Evrima Viewer 버전과 동일한 버전이라고 간주하지 않습니다.

```powershell
python scripts/update-stamina-data.py
python -m unittest discover -s tests -p 'test_stamina*.py'
node --test
```

## 원본과 계산 기준

- 원본: https://evrima-viewer.com/
- 초기 데이터: 0.21.784, 원본 추출일 2026-08-30, 확인일 2026-10-11
- 기본 능력치: https://evrima-viewer.com/data/v/0.21.784/species.json
- 성장률 t=0~1. 75% 미만은 Frail, 이후 선택한 Prime/Frail 경로.
- Linear / cubic Hermite / weighted tangent 보간과 마지막 키 고정을 재현.
- 질주: cm/s ×0.036 → km/h. 물기: AttackPower ×damageBite.
- 카르노 차징과 티렉스 Ambush는 원본 프런트엔드의 서버 측정 보정값.
- 스태미나 -0.78/s는 세부 단위가 미제공이므로 %/s로 해석하지 않음.
- 미출시·누락 항목은 `null` / 자료 없음. 전체 공룡의 스태미나 소모/회복/총량 자료는 원본에서 제공하지 않음.
- 게임 버전 최신 여부는 이 도구에서 별도로 확인하지 않음. '최신'은 원본 데이터 목록 기준.

Google Fonts 사용에 실패하면 시스템 글꼴로 표시됩니다. 계정 로그인, 분석 추적 및 API 키 없이 동작합니다.


## 간단한 비밀번호 잠금

GitHub Pages는 정적 호스팅이므로 이 잠금은 일반 방문자의 화면 접근을 제한하는 브라우저 기능입니다. 서버 인증이 아니며 공개 저장소와 내려받을 수 있는 코드·데이터를 분석하면 우회할 수 있습니다. 민감한 자료 보호 용도로 사용하면 안 됩니다.

평문 비밀번호는 파일·저장소에 넣지 않습니다. `data/access.json`에는 임의 salt와 PBKDF2-SHA256(600,000회) 검증값만 저장합니다. 확인 전에는 앱을 실행하지 않고, 같은 탭의 세션에서만 열림 상태를 유지합니다. **잠그기**를 누르면 세션 상태를 지웁니다. 비밀번호 검증값이 바뀌면 이전 세션으로 열리지 않습니다.

비밀번호를 변경하려면 다음 명령을 실행하고 숨겨진 표준 입력 프롬프트에 새 사이트 전용 비밀번호를 입력합니다. 검증값 변경을 커밋·push하면 적용됩니다.

```powershell
node scripts/set-password.mjs
```

화면 설정은 `evrima-compare-view-v2` 브라우저 저장소에 저장합니다. 이전 버전에서 처음 전환할 때 선택 공룡을 두 마리로 초기화하며, 이후 사용자가 바꾼 선택·그래프별 성장치·박스 순서·접힘 상태는 유지합니다. 수치 표의 체중/달리기/공격력은 각각 해당 그래프의 선택 성장치로 계산합니다.
